    Structured brief — separate fields for subject, environment, lighting, camera and mood
  • 02

    Locks AI starting point — same face, hair and skin tone generated every time
  • 03
    Set @img1 Character Reference
    Upload character sheet at maximum weight — anchors Aryan's face across all scenes
  • 04
    Use Real Tourist Reference
    Find a real tourist photo per Wonder — use as composition reference for authentic results
  • 05
    Generate · Review · Accept or Reject
    Cinematic model · 2K resolution · Check face consistency · Iterate or accept in workflow slide
Why JSON Prompts?
  • Plain text mixes everything — AI decides what matters
  • JSON gives every element its own dedicated field
  • Face · Lighting · Camera · Mood — all separate priorities
  • Change only the location field to move Aryan to a new Wonder
  • Organised list vs long sentence — results always better

Main Takeaways
  • Structured briefs produce predictable outputs — JSON prompts are the AI equivalent of a proper creative brief
  • Brand consistency at scale is solvable — fixed seed + character reference locks identity across unlimited scenes
  • Authenticity without a photographer — real tourist references eliminate the AI-composite look at zero extra cost
  • Workflow beats tools — same tool, different system, different result
  • AI influencer creation is repeatable — this workflow can be documented, handed off, and scaled
